# BARC core handoff v1

Generated by `python src/data/prepare_core.py`; validate with `python src/data/validate_core.py` (dependencies: `src/data/requirements.txt`). Full rules, citations, limitations and fold counts: [A acceptance report](../../../reports/a_data/README.md).

- `fields.geojson`: 83 source polygons, EPSG:4326, longitude/latitude; `area_ha` calculated in EPSG:26918; `farm_group` is source FARM_ID for grouped validation only.
- `labels.csv`: 44 labeled field-years on 34 fields, grain/silage, retaining label_raw. Blank source labels are omitted, not converted to grain.
- `smoke_sample.json`: barc_1, 2021, grain in labels.csv; [2021-04-01, 2021-12-01).
- `validation_folds.csv`: one frozen five-fold leave-one-farm-out scheme; 0-based fold IDs. Explicit task-authorized deviation from older contract's three field folds; no second validation table is published.
- `field_id_map.csv`: immutable mapping for this source version, source OBJECTID, original acres and farm group. Never regenerate IDs from row order.

Join geometries by string field_id; annual artifacts by field_id+integer year. Keep the original GeoPackage and legacy label CSV unchanged. All 83 polygons are not necessarily corn in each year; select and describe the annual target population explicitly. These are Maryland BARC data and provide no California validation. One transformed polygon (barc_301) has a documented negligible-area collapsed component repair; see acceptance.json.
