# 马里兰农田到奶牛场距离

仅使用44条带标签BARC田块年度记录（34块独立农田）和67个马里兰奶牛场相关地点。未使用海外、全国候选田或其余未标注BARC田块。

全部距离表共2948行；去重田块表共2278行。同一田块跨年的距离相同。距离矩阵每行一个田块年度，每个 dairy_*_km 列对应地点索引中的一个奶牛场。距离单位为公里；六位小数是存储精度，不是位置测量精度。

算法为WGS84椭球上的最短测地线。农田起点为田界内部代表点（先在马里兰UTM18N坐标系取point-on-surface，再转换回经纬度），终点为来源表给出的奶牛场地址点。不是道路行驶距离、实际农田出入口距离或田界边缘最短距离。

67个地点不一定对应67家独立企业；地址、门店及低精度道路参考点仍保留原location_precision，不将地址点冒充牛舍。另有1个无坐标地点无法计算，单独列出；2015历史候选表未使用。

全部地理计算在NVIDIA Brev实例执行，使用该机器CPU上的pyproj和Shapely；未在本地电脑或聊天中计算。结果附输入哈希、来源版本、范围及数值检查。
