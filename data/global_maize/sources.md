# Additional sources investigated
| Area | Evidence and access | Source |
|---|---|---|
| China, Hohhot | Survey and interpretation points, phenological observations, silage and grain mapping. Obtaining labelled survey polygons requires additional evidence. | https://www.mdpi.com/2073-4395/15/6/1438 |
| Canada, British Columbia | Published field maps, sampled soils and silage corn class. Vector files for these sampled polygons unverified. | https://www2.gov.bc.ca/assets/gov/farming-natural-resources-and-industry/agriculture-and-seafood/agricultural-land-and-environment/soil-nutrients/nutrient-management/technical-reports/soil-nutrient-studies/post-harvest_nitrate_study_-_final_report_-_sep_2017.pdf |
| Switzerland | Canton agricultural-use polygons. Historical code 508 is grain. Code 521 combines silo and green maize, requiring further evidence for silage. Check codebook for each year. | https://www.agi.dij.be.ch/de/start/geoportal/geodaten/detail.html?code=NUTZFL&type=layer |
| Japan, Hokkaido | Study compares silage fields to farm information. Public availability of paired reference geometries unverified. | https://www.jstage.jst.go.jp/article/jass/29/2/29_75/_pdf/-char/ja |
| United States, Maryland | Additional BARC combine-harvest yield archive with management information. Linking study records to challenge polygons requires original identifiers. | https://doi.org/10.1002/agg2.20474 |
| Brazil, Ukraine, USA, Canada, Russia | GloCAB contains manually digitized boundaries. Broad crop attributes alone cannot establish annual harvest type. | https://zenodo.org/records/10479122 |
| Europe | EuroCropsML combines parcel polygons and 2021 Sentinel-2 reflectance sequences. Independent verification of original harvest categories and duplicate fields is needed before combining with JRC data. | https://zenodo.org/records/13789558 |
