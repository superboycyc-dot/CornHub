Maryland BARC, United States. Source polygons and annual harvest labels are from the project-supplied 04_Evaluation/BARC_Corn.2021-2023.gpkg at the repository root. Original IDs are retained through field_id_map.csv. Join labels to features using field_id; retain year. The source has 83 polygons and 44 labelled field-years on 34 fields. barc_301 has a collapsed geometry component repaired in the project conversion. Original GeoPackage is available for comparison. The project's satellite time series and summary features cover barc_1 in 2021 only (Sentinel-2 L2A, Planetary Computer, 47 valid dates). Sensor coverage and filtering differ from the Dutch product. These files contain project reference labels and observations.
