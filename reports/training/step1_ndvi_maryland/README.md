# 第一步：马里兰官方数据，NDVI基线训练

在 NVIDIA Brev 机器 brev-wfu5hudhr 完成训练和验证。仅使用44条官方带标签田块年度记录（34块田，2021–2023）；32条籽粒、12条青贮。未读取奶牛场距离、海外或全国候选田。

模型为随机森林：100棵树，深度4，叶节点最少2个样本，平衡类别权重，随机种子42。预测变量为NDVI峰值、峰值日期、最大日下降速度、下降日期和晚季NDVI均值。观测次数和最长缺测间隔只用于质量校验，不进入模型。

按既有农场分组五折划分，逐折训练并预测未见农场；同一田不同年份不会跨训练/测试折。缺失值仅用训练折中位数补齐，训练列全缺失时填零。无超参数搜索、无验证集调参。

实际OOF准确率：81.82%（36/44），宏平均F1：0.7206，青贮召回率：41.67%。同样划分的多数类基准准确率：72.73%；差值：+9.09个百分点。

这里报告的是留出农场的预测结果，不是用训练数据评估自己。样本小，单折仅一个青贮训练样本等问题仍存在，概率未校准，未证明对其他地区或未来年份有效。第二、第三步没有运行。第二步须保持样本、标签、折分和模型配置不变，再报告加距离后效果实际提高、持平还是下降。

逐田结果见 oof_predictions.csv，实际指标见 metrics.json，折结果见 fold_metrics.json；模型保存在 models/，输入快照与来源哈希在 inputs/ 和 input_manifest.json，训练代码副本为 train_step1.py。计算在该NVIDIA机器的CPU执行；现有随机森林不需要GPU。
