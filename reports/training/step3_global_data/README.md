## 实际验证

|来源|同地区空间/农场分组OOF准确率|整国留出准确率|整国留出宏平均F1|
|---|---:|---:|---:|

|NL|82.30%|46.02%|0.3736|
|US|63.75%|52.50%|0.5100|

空间分组OOF的混合准确率为99.88%，全部猜籽粒也有99.69%；混合分数受到大量加拿大籽粒样本影响，不能作为全世界泛化准确率。各国家等权平均准确率：同地区分组82.02%，整国留出62.86%。

原44条马里兰基准在相同留出农场上加入外国训练样本后，准确率88.64%（39/44）；保留的本地模型为81.82%，差值+6.82个百分点。**不替换用户选定的81.82%模型。**

发现1条官方标签与整合作业证据冲突（barc_248/2023）；它们不参与全球训练、全球评分或马里兰训练折，只保留原官方测试标签作44条历史基准。排除冲突后的43条马里兰测试结果另见maryland_benchmark.json，训练集合与原44条完整训练设置有所区别。

## 缺失值与限制

5个NDVI衍生特征加最近奶牛场距离。部分缺失用每个训练折中位数加缺失指示器，整列在训练折缺失时保留为零和缺失标记；真实标签绝不填补。全部NDVI缺失的候选记录保留null且拒绝评分。海外距离未知仍为null，未用到马里兰奶牛场的跨洲距离替代。

按国家和类别平衡训练样本权重，避免加拿大样本数量压倒其他来源。空间验证的划分以农场/空间块为单位，整国留出完全排除测试国家；马里兰44条基准保持原五折，额外美国作业记录不混入该基准训练。参数、种子、阈值固定，没有根据第三步验证结果调参。

加拿大此次只有籽粒，荷兰仅局部样本；欧洲申报用途不等于逐田实收确认。单点NDVI与整田NDVI不同，2个日期的最大值不等于完整生长季峰值。缺测模式可代理来源地区，整国留出指标尤其重要。来源缺失、地域和年份迁移尚未解决，本次不是世界范围验证。历史马里兰数据已多次用于开发，不是新盲测。

数据清单、完整候选和训练Parquet、全部逐田预测、模型及源码均在NVIDIA运行目录中保存。Git报告包含指标、覆盖率、源哈希、逐田马里兰预测和模型校验和；完整模型包与全量逐田预测包保存在该NVIDIA运行目录，未复制到Git。原始输入可按input_manifest.json复取。代码放到/home/ubuntu/cornhub-compute/，用venv/bin/python train_step3.py运行，或用控制器train-step3任务。
