# 第二步：马里兰 NDVI + 最近奶牛场距离

仅在NVIDIA Brev运行；输入从GitHub提交 `4b1dd4ab834fbb4b3e8745d8f7c68453162f0121` 下载。保留第一步44条官方田块年度记录（34块田）、五折按农场留出划分和随机森林参数。没有加入海外、全国候选田、牛数、面积或ID作为预测变量。

在原5个NDVI衍生特征之外，仅新增 `nearest_dairy_distance_km`，为67个马里兰奶牛场地点中最近一个的WGS84椭球直线距离。这个定义在训练前确定，不根据测试结果搜索。逐田从2948条距离中重新取最小值，并核对所有年度键；同一田跨年距离相同。缺失值仍仅用训练折中位数填补。

准确率变化为 **-2.27个百分点**，实际结论 `degraded`。原来错误现在正确1条；原来正确现在错误2条。对照结果来自相同44条OOF预测，不使用训练内准确率，也没有反复挑选距离定义。

奶牛场位置资料于2026年整理，未逐场核实2021–2023年的历史位置和在营状态，所以只能作为当前地理代理的探索性比较，不能声称严格历史实时预测。位置近不等于实际饲料供需关系，地址点与田内代表点也不等于牛舍和农田出入口。样本小，概率未校准，不作统计显著性或全球表现承诺。
