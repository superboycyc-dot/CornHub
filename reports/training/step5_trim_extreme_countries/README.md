# 第五次实验：排除极端标签构成国家

仅用 NDVI 曲线特征训练，不输入国家、不按国家加权。先根据训练样本标签分布，预先定义两个筛选情景：

- 单一标签国家：CA。
- 极端偏斜国家：某国90%或以上记录属于同一收获标签；本批数据中为CA, NL。

沿用第四次实验已冻结的随机分折，同一田块/农场组仍只在一个折中。每个筛选情景都和第四步原模型在完全相同的保留田块、同一测试折上比较；训练参数、种子42和0.5阈值不变。

## 结果

|筛选情景|保留国家|记录数|旧全数据模型在保留行|筛后重训模型|准确率差|
|---|---|---:|---:|---:|---:|
|all_countries|CA, NL, US|39846|99.84%|99.84%|+0.00个百分点|
|exclude_single_label_countries|NL, US|193|67.88%|74.09%|+6.22个百分点|
|exclude_countries_with_at_least_90pct_one_label|US|80|40.00%|73.75%|+33.75个百分点|

这些结果只评价保留国家中的样本。剔除某国后得到的准确率不能说明模型能预测那个被剔除的国家；加拿大单一籽粒标签尤其无法检验青贮识别。不要只根据总体准确率选模型；同时查看宏F1、青贮召回和每国分项。

没有在看到分数后更改极端阈值、数据行、参数或折分。完整模型与逐行预测保存在 NVIDIA 本次运行目录。
