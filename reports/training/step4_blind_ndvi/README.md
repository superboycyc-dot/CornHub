# 第四次实验：隐藏国家的 NDVI-only 配对对照

主实验模型只看5个历史 NDVI 曲线指标：峰值、峰值日期、最大下降速度、下降日期、9月后均值。标签是籽粒/青贮。国家、地区、数据来源和奶牛场距离均不提供给主模型；训练不按国家加权。

为了检验去掉距离是否有帮助，另跑一个只多出最近奶牛场距离的配对对照。两个模型使用完全相同的田块、5折随机分组、随机种子42、随机森林参数和阈值0.5；所以这组差值只对应距离特征。分折按空间/农场组进行，同一组不会同时落入训练和验证。国家只用于完成预测后的成绩分表。

## 同一分折上的验证结果

|输入|记录数|正确|准确率|宏平均F1|青贮召回率|
|---|---:|---:|---:|---:|---:|
|ndvi_only|39846|39784|99.84%|0.8897|90.16%|
|ndvi_plus_distance|39846|39793|99.87%|0.8957|82.79%|

距离特征相对 NDVI-only 的准确率差：+0.02 个百分点。国家等权准确率：NDVI-only 75.87%，NDVI+距离 79.62%。

|NL|113|87.61%|87.61%|95.19%|

跨国家合并准确率受加拿大39,653条全为籽粒的记录主导，全部猜籽粒本身已有较高基线；因此重点看宏平均F1、青贮召回和分国家成绩。加拿大只有籽粒标签，不能测其青贮识别。

与第三步整体结果不作严格增减比较：第三步按国家和类别加权，使用不同分折。这次两个实验臂之间是严格配对比较。历史马里兰数据已反复用于开发，不是独立盲测。
