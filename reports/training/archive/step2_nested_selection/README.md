# 第二步改进实验：嵌套分组选择

全部训练在NVIDIA Brev执行，仅使用原44条马里兰官方田块年度记录和奶牛场距离。保留原五个留出农场，每个外层折只在训练农场内部用留一农场验证选择模型、距离表达和阈值。种子固定42，不搜索随机种子。所有候选定义在protocol.json，并保存每个候选的内部得分。内部训练集缺少一类时使用显式常量分类器，不能从外层测试标签补充信息。

|方案|外层预测准确率|正确条数|宏平均F1|青贮召回率|
|---|---:|---:|---:|---:|
|原第一步NDVI|81.82%|36/44|0.7206|41.67%|
|原第二步最近距离|79.55%|35/44|0.6979|41.67%|
|本轮嵌套选择NDVI对照|72.73%|32/44|0.4903|8.33%|
|本轮嵌套选择NDVI+距离|70.45%|31/44|0.4776|8.33%|

本轮距离方案比原第一步变化-11.36个百分点，比原第二步变化-9.09个百分点，比本轮同样调优的NDVI对照变化-2.27个百分点。不能把不同模型调优带来的变化全部归因于奶牛场距离。

候选包含固定随机种子的随机森林、极端随机树、标准化逻辑回归；距离表达为最近距离或最近1/3/5场距离和逆距离暴露度的汇总。每折阈值仅用内层OOF预测选择，不使用外层测试标签。用于部署的全量模型另行在44条上通过分组CV选择，不把训练内分数当验证分数。

**限制**：之前已反复查看这44条数据的验证结果，因此本轮属于开发集再实验，不是全新的独立盲测。只有5个农场，少数折类别极少；没有显著性或真实部署性能保证。奶牛场资料为2026年整理，历史在营状态未逐场核实，直线距离也不等于实际供需或道路距离。原来79.55%的负结果保留不变，不覆盖旧报告，不删除不利候选。第三步未运行。
