# CornHub 使用方法与验证步骤

本页是团队后续实现的操作规范建议。它不是已执行的训练记录，也不修改 B 的遥感代码或 C 的分类模型。

## 1. 先选择要解决的问题

| 当前数据条件 | 可研究的方法 | 开始之前要验证 |
| --- | --- | --- |
| 有可信参考或可以验证的噪声模拟 | DnCNN | 参考是否适合作目标、模拟是否接近实际噪声 |
| 有同一真实地表状态的两次带噪观测 | Noise2Noise | 精确配准、状态稳定、噪声的独立/无偏条件 |
| 只有晴空但带随机噪声的影像 | Noise2Void | 噪声空间相关性、盲点假设是否成立 |
| 需要重建云区且有配准的 S1/S2 | DSen2-CR | 云影掩膜、光学/SAR 对齐、可比较无云参考 |
| 需要利用多个日期补云 | SEN12MS-CR-TS 相关方案 | 时间窗口、真实物候变化和可用参考 |

如果没有证据说明普通随机噪声是主要问题，先使用已有 QA 掩膜和未去噪影像作为对照。SAR 斑点、光学随机噪声、条带、云遮挡和指数曲线尖峰不能默认用同一种噪声模型处理。

## 2. 准备输入和来源记录

1. 用真实稳定 field_id、year、date、sensor、scene_id 关联数据，先查重复键和错位；不从 RGB 截图代替多光谱原始数据。
2. 记录产品处理级别、波段、空间分辨率、有效掩膜与物理缩放。Landsat SR、Sentinel-2 L1C 和 L2A 的输入口径不同，不互套缩放或权重。
3. 准备配准的多波段 patch。掩膜按离散类别处理；重采样可能改变噪声相关性，必须在实际预处理后检查。
4. 隔离 nodata、云影、雪及对应产品规定的无效值。无云参考不等于完全无噪声，更不等于与输入日期地表状态相同。
5. 对参考时间错位特别检查：不要让“收获前→收获后”的真实变化成为应被消除的噪声。
6. 先按地理区域/田块划分训练、验证、测试，再切 patch；重叠 patch 不可随机分散到两侧。归一化等拟合仅使用训练部分。

所有输入和参考应保留传感器、日期、产品 ID、处理版本及授权来源。来源不明或许可未核实的数据不直接重新分发。

## 3. 各方法怎样组织训练

- **DnCNN**：输入带噪影像，目标为输入减参考的残差；推断时用输入减去预测残差。若模拟加噪，保存噪声类型、参数、种子，并把模拟结果与真实噪声实验分开。
- **Noise2Noise**：输入第一幅、监督目标第二幅；先证明两者对应同一地表状态。仅仅“同一田块、不同日期”不足以满足条件。
- **Noise2Void**：只在有效区域随机选监督位置、替换其输入值，损失仅在这些位置计算，避免学到复制输入。在多波段情况下要验证跨波段噪声相关性，防止中心像元信息从其他波段泄漏。
- **DSen2-CR**：按作者方案构建有云 S2、S1、无云参考三元组和云/云影掩膜；使用 CARL 或明确命名的对照损失。核对作者预处理后再迁移，不能只更换波段名。
- **多时相去云**：按作者具体模型组织时间序列，不把概念框架当现成实现。若声称日期 t 的实时预测，禁止使用 t 之后的影像；收获后回顾任务按主办方允许窗口设置。

建议先用小样本验证输入、掩膜和损失，再扩大训练。学习率、batch size、epoch 和 lambda 需通过实际验证确定，本报告不编造 CornHub 的最佳参数。

## 4. CARL 的 PyTorch 示意

以下是公式的最小表达，**本次没有运行**，不包含网络、数据加载或训练循环。假设光学张量为 BCHW，掩膜为 B1HW，已验证尺寸、二值掩膜和有限值；全部参加计算的输入/参考元素必须有效。

```python
# pred, target, optical_input: same-shape BCHW optical tensors
# cloud_shadow_mask: B1HW; 1=cloud/shadow, 0=clear
# lam: explicitly chosen experiment parameter

def carl_loss(pred, target, optical_input, cloud_shadow_mask, lam):
    mask = cloud_shadow_mask.to(dtype=pred.dtype)
    adaptive = mask * (pred - target) + (1 - mask) * (pred - optical_input)
    return adaptive.abs().mean() + lam * (pred - target).abs().mean()
```

如果需要额外处理无效区域，应对损失和有效元素数量一起做掩膜，并明确命名为“有效区扩展”；它不再是对完整输入直接使用的原文实现。不要把缺测 target 填 0，再让网络学习填充值。

## 5. 推断、保存及验收

推断时保持与训练一致的波段顺序、单位、配准和预处理。保留原始观测及 QA 掩膜，不用输出覆盖原件。区分 observed、denoised、reconstructed 等来源状态，记录模型版本及使用的日期；这些是建议新增的状态设计，本次尚未生成相关数据。

验证至少分三层：

1. **光谱/影像**：逐波段 MAE/RMSE，晴空区域是否被无故改变，云区重建是否合理。PSNR/SSIM 不能单独证明光谱保持。
2. **农业特征**：有效参考区域中的 NDVI/NDMI 误差；田块边界、峰值日期和收获突变是否被平滑或移动。不同日期的真实物候变化不能当去噪误差。
3. **最终任务**：与同一候选集、同一数据划分的未去噪基线比较。分类结论只用真实标签和按田块独立的 OOF 结果；不把训练分数、视觉美观或单个田块概率称为已验证准确率。

厚云下重建是模型估计，不能计作新增真实观测，也不直接进入既有“真实有效覆盖率”。若另算估计覆盖率，需要独立字段和规则。未做足参考验证前，重建 NDMI 不用来宣称真实含水率、分类改进、面积收益或利润。
