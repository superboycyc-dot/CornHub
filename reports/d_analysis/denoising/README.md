# 卫星影像去噪与去云：公式、论文和使用方法

本次交付是文献整理与实施说明，未训练或运行去噪模型、未生成重建影像，也没有改动模型、遥感或前端代码。此前的 CuPy NDMI 计算后端不是去噪网络，不能视为已有训练结果。

- [公式与符号](FORMULAS.md)：4 个训练目标及多时相去云框架，注明论文公式编号和简化写法。
- [CornHub 使用步骤](USAGE.md)：如何选方法、准备数据、训练和验证；包含 CARL 损失的 PyTorch 示意。
- [论文与作者代码来源](sources.csv)：完整题名、作者/组织、年份、链接、查阅时间和适用条件。

对 CornHub 的方法选择属于本报告建议，不是上述论文在 BARC 上验证过的结论：先明确是随机噪声、云遮挡，还是 NDVI/NDMI 时序的异常。云下缺失信息需要推断；推断不能标成真实观测。先保留现有 QA 掩膜及未去噪输入作为对照，是否引入 AI 由独立验证决定。
