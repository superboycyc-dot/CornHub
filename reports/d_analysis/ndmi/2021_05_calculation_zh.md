## 计算步骤

1. 读取 Maryland 州界与 2021 年 USDA CDL 原始分类，选取 class 1 Corn；使用 EPSG:5070 固定 30 米网格，像元中心须位于州内。
2. 检索 2021-05-01（含）至 2021-06-01（不含）的 Landsat 8/9 Collection 2 Level-2 Tier 1。这个月份实际使用 Landsat 8。
3. 去除 QA_PIXEL bits 0–5 标记的缺失、云、云影、雪等，以及 QA_RADSAT bits 4、5、11；去除 DN=0、负反射率、非正分母和越界指数。
4. B5、B6 先缩放成地表反射率，再逐像元计算 NDMI：

```text
rho_B5 = DN_B5 × 0.0000275 − 0.2
rho_B6 = DN_B6 × 0.0000275 − 0.2
NDMI = (rho_B5 − rho_B6) / (rho_B5 + rho_B6)
```

5. 场景按整体云量、距当月 15 日的时间距离、日期和 ID 排序。对每个玉米像元选首个有效观测，形成月度拼接；每像元最多计一次。最终均值为 2,182,710 个有效像元 NDMI 的等面积空间均值，不是所有过境观测的时间平均，也不是反射率均值之比。
6. 每个网格像元为 0.09 ha，因此有效面积为 2,182,710×0.09=196,443.90 ha，覆盖率为 2,182,710/2,301,070=94.8563%。其余区域保留缺测。

## 一个真实像元

产品 `LC08_L2SP_016033_20210520_02_T1`；目标网格 row=1784、col=1231；EPSG:5070 坐标 (1433565.0, 1984215.0)。

```text
DN_B5 = 16746
DN_B6 = 15994
rho_B5 = 16746×0.0000275−0.2 = 0.260515
rho_B6 = 15994×0.0000275−0.2 = 0.239835
NDMI = (0.260515−0.239835)/(0.260515+0.239835)
     = 0.04133107
QA_PIXEL = 21824，上述剔除 bits 均为 0
QA_RADSAT = 1，B5/B6 饱和和地形遮挡 bits 均为 0
```

这个像元的指数不是全月区域均值。原始像元示例、十个贡献场景及未签名波段地址均保存在 `data/processed/analysis/ndmi/months/2021_05.json`。

## 复跑与核查

```sh
python src/analysis/ndmi/calculate.py --year 2021 --month 5 --workers 1
```

依赖安装、来源、完整 QA 规则及断点续算见本目录 README.md。若月度 JSON 已存在，上述命令复用它；要从头重算，应将已有月份结果移走并使用新的 `--cache`。

本月核查：贡献场景像元数之和等于有效像元数；面积和覆盖率计算一致；真实 DN 示例重算差异小于 1e-7；读取异常为零。批量导出检查见 validation.json。

NDMI 无单位。此均值只描述 94.86% 的有效区域，不是土壤含水量百分比。接近零不能单独判断干旱或作物健康：本范围来自年度玉米分类，5 月可能包含裸地或早期生长区域；缺测、物候和实际观测日期也会影响均值。没有据此推断 silage/grain 或利润。
