# CornHub

利用公开卫星时序识别玉米田的青贮（silage）或籽粒（grain）收获用途，并展示数据质量、预测不确定性和人工核查建议。

## 当前研究范围

以主办方提供的马里兰州 Beltsville Agricultural Research Center（BARC）2021–2023 年标注为准。原始数据含83块田边界；其中34块不同田有44条有效田块年度标签（32 grain、12 silage）。空白标签不代表grain，也不能据此确认当年种玉米。

第一阶段使用44条标注验证方法。其余田块年度是候选扩展对象，需先核实当年玉米种植资格，再提取对应观测；不能直接将所有83块田三年全当玉米预测。加州CDL、Quick Stats等已有资料仅为独立历史参考，不作为当前研究范围、训练标签或泛化证明。

## 已实现与待验证的改进

- 已实现：44个田块年度的Sentinel-2 NDVI时序与特征；按农场留出的五折Random Forest验证；分年度面积估计与核查模拟。
- 已交付：4524条田块—场景记录、44行特征、44条OOF和44条inference。它们不代表88个独立样本。
- 当前模型概率未校准。最新成果仍需查看各角色PR/分支，不能认为所有代码和数据已经合入main。
- 拟验证：补充NDMI水分时序及其与NDVI的联合特征，在同一44条标签、同一农场划分上比较NDVI基线和NDVI+NDMI。此项尚未实现，不保证提升准确率；增加观测不等于增加独立标签。
- 当前输入覆盖完整季节，属于回顾性用途识别。若改为收割前预测，必须冻结预测日，只使用此前可得观测并重新验证。

## 模型、质量与核查的关系

模型预测类别和p_silage；数据质量另报告有效观测、缺口、收获窗口覆盖和空间像元支持。概率接近0.5、模型间分歧、输入超出训练分布可作为不确定性线索，但未经留出检验不能叫正确率。

核查优先级应结合不确定性、田块面积及观测证据，不能仅按“可信度低”排序。首版保留合同area_ha*4p(1-p)启发式及独立质量待补清单；后续规则需在相同OOF样本和预算下与随机核查比较，不按测试结果反复调规则。2021全部limited，不为了演示放宽质量门槛。2023核查模拟出现总量误差增大，必须保留该结果，不宣称核查必然改善。
