## 3. 数据处理工作流

### 3.1 Quick Stats

输入：01_QuickStats/corn_grain_silage_acres_2012_2025_raw.csv，39,906 行。它包含全国、多类子系列与多种时期，不能直接把原表相加当作年度总量。

1. 检查列名与记录，用原始 short_description 确认三类精确序列：CORN - ACRES PLANTED、CORN, GRAIN - ACRES HARVESTED、CORN, SILAGE - ACRES HARVESTED。
2. 下载器增加精确序列、YEAR、ANNUAL、TOTAL、NOT SPECIFIED 过滤，排除灌溉/有机子系列及其他参考期。下载器的联网请求本轮没有重新执行。
3. 新建 scripts/curate_quickstats.py，在本地源 CSV 上额外筛 California；2012/2017/2022 用 COUNTY+CENSUS，其余年用 STATE+SURVEY。
4. 按 year、aggregation_level、state_ansi、county_ansi、short_description 检查唯一键，重复即报错；不静默去重。
5. 保留 value、CV、来源等原文本；(D) 等抑制值不转 0，FIPS 保留字符串。
6. 输出 data/processed/usda_nass/california_corn_acreage_annual_reference_2012_2025.csv，225 行。早期本地全国派生稿 15,880 行已在加州范围确定后移除，未当作最终加州结果提交。

注意：脚本沿用输入文件的 2012–2025 范围，没有根据 CLI 参数下载或保证 2026 已可用。2012–2021 是历史参考，不能悄悄混入 README 所述加州 2022–2026 验收。COUNTY/CENSUS 和 STATE/SURVEY 的切换是整理规则，不证明其他年份没有县级数据。

### 3.2 BARC 标签

输入：04_Evaluation/BARC_Corn.2021-2023.gpkg；图层 barc_silage_grain_corn20212023。

1. 用 SQLite 只读访问 GeoPackage，读取 OBJECTID、ACRES、Corn_2021/22/23；只选择精确 Grain/Silage 标签。
2. 空标签忽略，不把 83 块田全部当训练样本。
3. 输出四列 field_id/year/harvest_type/acres；field_id 为源 OBJECTID 的字符串，面积使用源 ACRES，保留六位小数。
4. 统计得到 44 个标签年度、34 块独立田；逐年 Grain/Silage 为 14/4、3/4、15/4。

限制：此脚本没有做几何修复、投影面积重算、GeoJSON、稳定前缀 ID、来源列、共同样本或 validation_folds；它不是 team-contract 的 A 完整交付。GeoPackage 的自定义 srs_id=100000 不能直接当成 EPSG:100000；投影应读取实际 CRS 定义。

### 3.3 BARC Sentinel-2 notebook 草稿

已写的流程：读取 BARC 标签/农场 → 投影几何 → WGS84 AOI 查 Planetary Computer → 获取 B04/B08/SCL → 10 m 网格和 SCL 4/5 掩膜 → 逐田 NDVI 中位数/有效比例 → 季节特征 → 按农场 GroupKFold → RF 与多数类基线 → OOF 概率与面积误差草稿。

本会话修正过：补 xarray 导入；把传给 load 的无 CRS 投影几何改成 WGS84 GeoJSON；把 groupby.apply 的 include_groups=False 移除以避免函数读取 year 列缺失；保留 vegetation/bare-soil SCL；增加 OOF 概率表；明确马里兰样本和未校准限制。

**这些修正只通过静态语法检查，没有运行遥感或训练。** 代码单元 execution_count 全为空、outputs 全为空。本轮进一步阅读发现的 dtype/offset、pandas 兼容、空时序、同日合成、低有效比例、跨年面积等待查问题，详见 agent-handoff。不能把 notebook 当成已完成且符合团队合同的程序。
