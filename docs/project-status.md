## 5. 何时能向评审说“完成”

- 一块真实田有可追溯标签、边界、真实影像时序；缺测也如实展示。
- 真实标签集有明确保留划分，报告年份/类别/田块数量、两类 precision/recall 和混淆矩阵。
- 同一田的跨年信息不泄漏到训练与验证两侧；任何校准只使用训练部分。
- 面积按单一年份、单一 prediction_role 汇总，缺测不算 Grain，BARC 面积不外推到加州。
- 网站引用同一套合同产物；未训练/未计算显示空状态；方法限制和误判案例可解释。
- 可从原件复跑，记录环境、命令、数据版本、观测截至日期与文件来源，保存实际 notebook 输出。
